Solo Project

CarePolicyGuard

Policy-aware clinical coverage verification engine

  • FastAPI system combining deterministic clinical rules and verification agents to check EHR patient records against CMS Medicare coverage determinations (NCD/LCD) for prior-authorization reviews.
  • Achieved 98.5% decision concordance and 100% evidence faithfulness on a self-built benchmark of clinical test vignettes across cardiology, pulmonology, and wound care, with 33.3% safely deferred to human review.
FastAPIPython 3.12 Deterministic Rule EngineRAGPHI Masking

Inside CarePolicyGuard

Explore the flow

From raw clinical EHR text to deterministically verified prior-authorization decisions against source text. Select a step to learn more.

01 / RETRIEVALPolicy & Criteria Ingestion

Retrieves governing Medicare NCD/LCD policies (such as ICD, PAP, TAVR) using hybrid lexical-semantic chunk matching, then extracts clinical criteria with character offset anchors.

02 / VERIFICATIONSource-text verification

A verification pipeline confirms character slices directly against raw EHR source text to guard against extraction errors, quote drifts, and negative omissions.

03 / DECISIONCalibrated Gate & Defense Packet

Enforces a calibrated confidence gate (τ = 0.85); cases falling below the threshold route safely to human auditors, while verified decisions generate complete CMS appeal defense packets.

Empirical Benchmark: 98.5% decision concordance and 100% evidence faithfulness on a self-built benchmark of clinical test vignettes across cardiology, pulmonology, and wound care (33.3% safely deferred to human review, ECE 0.032) vs. a zero-shot prompt baseline (66.7% accuracy, 48.5% faithfulness, ECE 0.274).

My contribution: Sole author of the full system architecture, FastAPI microservice, deterministic clinical rule engine and slice validators, PHI minimum-necessary masking, and benchmark evaluation suite.

Inside Parallax-Eval

Explore the flow

From paired prompts to a comparison of model safety behavior. Select a step to learn more.

01 / EXPERIMENTCompare two languages

Run equivalent English and Nepali prompts through the model gateway. The Flutter client connects to FastAPI to monitor experiments and inspect paired responses.

02 / EVALUATIONCheck safety judgments

Policy retrieval supplies context to a LangGraph Judge/Critic/Arbiter workflow. The agents evaluate responses, challenge classifications, and reconcile disagreements. Adaptive red-teaming explores prompt variations.

03 / ANALYSISInspect the differences

Compare refusal, unsafe compliance, and over-refusal behavior using paired statistical tests and bootstrap confidence intervals. Execution traces track latency, token usage, and estimated costs; CLI tools support dataset verification and regression checks.
