Inside Parallax-Eval

Explore the flow

From paired prompts to a comparison of model safety behavior. Select a step to learn more.

01 / EXPERIMENTCompare two languages

Run equivalent English and Nepali prompts through the model gateway. The Flutter client connects to FastAPI to monitor experiments and inspect paired responses.

02 / EVALUATIONCheck safety judgments

Policy retrieval supplies context to a LangGraph Judge/Critic/Arbiter workflow. The agents evaluate responses, challenge classifications, and reconcile disagreements. Adaptive red-teaming explores prompt variations.

Compare refusal, unsafe compliance, and over-refusal behavior using paired statistical tests and bootstrap confidence intervals. Execution traces track latency, token usage, and estimated costs; CLI tools support dataset verification and regression checks.
